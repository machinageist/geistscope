- `skills/` — GeistScope-specific agent skills/playbooks
- `memory/` — old Claude project memory snapshots preserved near the repo
- `REDBROWSER_PROJECT.md` — legacy RedBrowser context, now treated as GeistScope historical context

For implementation, prefer repo-local `docs/`, `.hermes/`, and code-adjacent specs over global agent directories.
