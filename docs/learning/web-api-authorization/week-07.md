# Week 07 — Evidence quality: candidate, negative, and invalid

Status: active learning unit

## Weekly goal

Practice classification discipline so that uncertain observations remain useful without becoming false claims.

## Expected private artifact

One classification-focused case file that makes uncertainty explicit.

## Before you start

- Use only the authorized training environment selected for this unit.
- Keep credentials and session material out of the notebook.
- Use the [private case-file template](CASE_FILE.template.md) and update private `INDEX.md`.
- Do not add or revive GeistScope product features while completing this unit.

## Session 1 — Protocol/study (90 minutes)

### 0–30 min — Review the three result layers

Read the result-layer section in the learning track. Define `candidate`, `negative`, and `invalid` in your own words and list what evidence each requires.

### 30–60 min — Compare ambiguous cases

Create three synthetic mini-scenarios: changed response with unknown ownership, explicit denial, and known cross-account data. Classify them and explain why.

### 60–90 min — Source case-study slot

If two more private artifacts are complete, perform `code-study-003` on one small frozen model or validation path that distinguishes accepted input from ambiguous input. Otherwise keep studying classification.

## Session 2 — Controlled lab (90 minutes)

### 0–30 min — Select for ambiguity

Choose a lab or path where you must establish context carefully. The goal is not necessarily to find a vulnerability; it is to classify honestly.

### 30–60 min — Collect minimum evidence

Capture only redacted facts needed to explain identity, object ownership, expected behavior, observed behavior, and limitations.

### 60–90 min — Decide and defend classification

Write a short defense for the classification. Include the strongest alternative explanation and what additional evidence would change the conclusion.

## Session 3 — Private notebook and retrospective (90 minutes)

### 0–30 min — Create case file 007

Use the case template with special attention to limitations and next safe verification step.

### 30–60 min — Audit classification distribution

Review INDEX.md. If one class is absent, identify a controlled way to practice it; do not relabel old cases to fill a quota.

### 60–90 min — Check for overclaiming

Read each case title and first paragraph. Remove wording that says or implies `verified`; the learning-phase ceiling is candidate, negative, or invalid.

## End-of-week check

Run the five mandatory weekly retention questions in [the quiz protocol](QUIZ_PROTOCOL.md) before starting the next week. The questions below are supplemental retrospective prompts.

Before starting the next unit, answer:

1. What did I observe directly?
2. What did I infer, and what evidence limits that inference?
3. What remains unknown?
4. Did any manual friction recur in at least three documented cases?
5. Did I stay inside the learning-phase automation and data boundaries?

If an answer is unclear, record it as a gap. Do not solve it by expanding scope or building a tool.
